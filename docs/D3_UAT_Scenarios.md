# **UAT (User Acceptance Testing) Scenarios**

## **Scenario 1: นักศึกษา ลงทะเบียนและยกเลิกการลงทะเบียน**

Objective: นักศึกษาสามารถลงทะเบียน ดูประวัติการลงทะเบียน และยกเลิกการลงทะเบียน

Steps:

1. เปิดเบราว์เซอร์ไปที่ [Workshop Hub](https://workshop-alpha-brown.vercel.app/)  
2. กรอกอีเมล @buu.ac.th และรหัสผ่าน กดปุ่ม 'เข้าสู่ระบบ'  
3. ค้นหา workshop ที่สนใจ  
4. เลือก workshop ที่สนใจ กดปุ่ม 'Register'   
5. ดูรายการกิจกรรมที่ลงทะเบียน  
6. ยกเลิกกิจกรรมที่ลงทะเบียน กด 'ยกเลิก'

Expected Outcome

* ✓ เข้าสู่ระบบสำเร็จ เข้าสู่หน้า Workshop Online Registration  
* ✓ แสดงรายละเอียด Workshop วันที่, สถานที่, จำนวนผู้เข้าอบรม, รายละเอียดเพิ่มเติม  
* ✓ ลงทะเบียน Workshop สำเร็จ แสดงข้อความ "ยืนยันการลงทะเบียน: (ชื่อWorkshop) สำเร็จ\!"  
* ✓ แสดงรายการกิจกรรม Workshop ที่ลงทะเบียนสำเร็จ  
* ✓ สามารถกดยกเลิกกิจกรรมที่ลงทะเบียนได้

## **Scenario 2: ผู้จัดอบรม ลงทะเบียนกิจกรรม จัดกิจกรรมอบรม แก้ไขกิจกรรมที่จัด**

Objective: ผู้จัดอบรมสามารถลงทะเบียนเข้าร่วมกิจกรรม จัดกิจกรรมอบรมและแก้ไขรายละเอียดกิจกรรมที่จัดได้

Steps:

1. เข้าสู่ระบบด้วยบัญชีบุคลากร   
2. เลือกกิจกรรมที่ต้องการลงทะเบียน กดปุ่ม 'Register'  
3. สร้างกิจกรรมอบรม กดปุ่ม 'Create Workshop'  
4. แก้ไขกิจกรรมที่จัด กดปุ่ม 'บันทึกการแก้ไข'

Expected Outcome

* ✓ เข้าสู่ระบบสำเร็จ เข้าสู่หน้า Workshop Online Registration  
* ✓ แสดงรายละเอียด Workshop วันที่, สถานที่, จำนวนผู้เข้าอบรม, รายละเอียดเพิ่มเติม  
* ✓ ลงทะเบียน Workshop สำเร็จ แสดงข้อความ "ยืนยันการลงทะเบียน: (ชื่อWorkshop) สำเร็จ\!"  
* ✓ แสดงข้อมูลการสร้างกิจกรรม workshop ใหม่สำเร็จ แสดงข้อความ "สร้าง Workshop ใหม่สำเร็จเรียบร้อยครับ\!"  
* ✓ แสดงข้อความ "อัปเดตข้อมูล Workshop สำเร็จ\!"

## **Scenario 3: ผู้อนุมัติ ทำการตรวจสอบกิจกรรม และอนุมัติกิจกรรม**

Objective: ผู้อนุมัติสามารถตรวจสอบความถูกต้องของกิจกรรม และสามารถอนุมัติกิจกรรมได้

Steps:

1. เข้าสู่ระบบ ตรวจสอบว่า Dashboard แสดงกิจกรรมที่รอการอนุมัติ  
2. เปิดดูรายละเอียดตรวจสอบความถูกต้องของกิจกรรม  
3. กดปุ่ม 'Approve' เพื่ออนุมัติกิจกรรม กดปุ่ม 'ยืนยัน'  
4. กดปุ่ม 'Reject' กิจกรรมที่ไม่ถูกต้อง กดปุ่ม 'ยืนยัน'

Expected Outcome

* ✓ เข้าสู่ระบบสำเร็จ เข้าสู่หน้า Workshop Online Registration  
* ✓ Admin Dashboard แสดงข้อมูลกิจกรรมที่รออนุมัติ  
* ✓ แสดงรายละเอียดกิจกรรมทั้งหมด  
* ✓ Approve แสดงข้อความ "คุณแน่ใจหรือไม่ที่จะ approved งานนี้?" แสดงข้อความ "อัปเดตสถานะเป็น approved เรียบร้อยแล้ว\!"  
* ✓ Reject แสดงข้อความ "คุณแน่ใจหรือไม่ที่จะ rejected งานนี้?" แสดงข้อความ "อัปเดตสถานะเป็น rejected เรียบร้อยแล้ว\!"

## **Scenario 4: ผู้ดูแลระบบ จัดการสิทธิ์ผู้ใช้งาน**

Objective: ผู้ดูแลระบบสามารถจัดการสิทธิ์ผู้ใช้งาน 

Steps:

1. เข้าสู่ระบบ ตรวจสอบว่า Dashboard แสดงกิจกรรมที่รอการอนุมัติ  
2. จัดการสิทธิ์ผู้ใช้งาน กดปุ่ม 'จัดการผู้ใช้งาน'  
3. เปลี่ยนสิทธิ์ผู้ใช้งาน กดเลือกสิทธิ์ที่จะเปลี่ยน (STUDENT, ORGANIZER, APPROVER, ADMIN)

Expected Outcome

* ✓ เข้าสู่ระบบสำเร็จ เข้าสู่หน้า Workshop Online Registration  
* ✓ Admin Dashboard แสดงข้อมูลกิจกรรมที่รออนุมัติ  
* ✓ แสดงรายละเอียดผู้ใช้งาน   
* ✓ จัดการสิทธิ์ของผู้ใช้งาน เปลี่ยนสิทธิ์สำเร็จ แสดงข้อความ "อัปเดตสิทธิ์เรียบร้อย\!"
